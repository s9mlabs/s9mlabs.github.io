07Questions

What engineers
ask us first.

Something we didn’t cover? Write to team@s9mlabs.com.

The field builds outside in: build the behavior first, then say the inside must match. We build inside out: see what is actually happening in the brain, then build the machine. Imitate from the lowest layer, and imitation turns into emulation.

Computing is the manipulation of electricity, and every layer above it is an abstraction. AI is built up there, on a neuron drawn as a switch because machines already ran on binary. We start one layer lower, at electricity, where the brain is wired too.

Today’s AI only scales up. More layers, more compute. Gigawatt data centers, for text alone.

We design everything. Partners build it in. On-device models first, then robotics and drones, then brain-computer interfaces.

We study the most efficient intelligent system on the planet, and use it as the ground truth for how we build AI. Our scientific advisor, Peter Voss, is one of the pioneers of AGI: he co-coined the term.
